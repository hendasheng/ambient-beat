# Beat Sync Monitor

Beat Sync Monitor 是 Ambient Beat 中的节拍同步监视器实验。

项目目标是借用 FFmpeg `avsynctest` 的黑底、高对比、参数标注式视觉语言，但把测试参数替换成 Ambient Beat 当前节拍状态：BPM、当前拍、每小节拍数、小节编号和播放状态。

v0.1 的画面保持克制：纯黑背景、分散的小号白色等宽文本、一排按小节划分的细竖线刻度，以及表示小节进度的白色实心块。4/4 拍时整条刻度分成 4 段，每拍只走其中一段。

## Versions

- [beat_sync_monitor_0.1](./beat_sync_monitor_0.1/)：建立黑底测试画面、分散式实时节拍文本、小节刻度、实心进度块、交互式隐藏控制面板和 Web Audio 点击声。

## 设计方向

- 保留测试仪表盘式的清晰可读性。
- 文本层优先显示当前节拍，而不是装饰性说明。
- 视觉反馈主要由小节刻度和实心块承担，避免用大面积背景闪烁控制节奏。
- 视觉进度与音频点击共享同一个调度时钟，方便观察同步感。
- 后续版本可以加入导出素材、延迟校准、tap tempo 和多种文本布局。
